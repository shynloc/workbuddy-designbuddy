# 颜色

加载标记：`ALPHA-REF-COLOR`

| token | 名称 | 值 | 用途 |
|---|---|---|---|
| `color.primary` | Alpha Blue | `#1F4FD8` | 标题强调、按钮、图表主序列 |
| `color.ink` | Ink | `#111827` | 正文文字 |
| `color.paper` | Paper | `#FFFFFF` | 页面背景 |
| `color.mist` | Mist | `#EEF2FF` | 卡片与分区背景 |
| `color.accent` | Signal Amber | `#B45309` | 少量高亮、数据标注点；禁止用作文字色 |

必须达标的组合：正文 / 页面背景 ≥ 4.5:1；页面背景色文字 / 主色填充 ≥ 4.5:1；强调色仅限非文字 UI（≥ 3:1）。
