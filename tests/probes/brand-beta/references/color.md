# 颜色

加载标记：`BETA-REF-COLOR`

| token | 名称 | 值 | 用途 |
|---|---|---|---|
| `color.primary` | Beta Rust | `#9A3412` | 标题、引言线、按钮 |
| `color.ink` | Charcoal | `#1C1917` | 正文文字 |
| `color.paper` | Cream | `#FFF7ED` | 页面背景 |
| `color.sand` | Sand | `#FED7AA` | 装饰色块、分区背景 |
| `color.accent` | Teal Note | `#0F766E` | 链接与少量点缀 |

必须达标的组合：正文 / 页面背景 ≥ 4.5:1；页面背景色文字 / 主色填充 ≥ 4.5:1；强调色仅限非文字 UI（≥ 3:1）。
